## 居然有诈骗邮件发到我头上

这周在上班的时候突然看到我的学校邮件收到了一条邮件，说的是**大学生补助申请**的。

我寻思我都毕业了还哪来的大学生补助申请，而且这个域名看上去就不像是什么官方网站。

![[2026-07-2nd_bug-x-premium-20260723_23-38-28.webp]]

于是没有着急点开这个网站，先是把网站复制了出来然后丢到腾讯检测了一下，报钓鱼网站；然后又是用 [whois](https://www.whois.com/whois/) 查询了一下网站的注册信息，没想到注册人都能够清清楚楚的看得到，而且域名售卖商也不是什么大公司。

到这里已经很明显可以看出来这是一个钓鱼网站了。刚好我买的 opencode go 好像还没怎么用，于是就到了我用国模看看能不能逆向的时候了。

刚好我也是刚刚配置好了我的 Pi，于是接了一个 MCP 就让它自己去折腾去了。

没想到过了一会我回来看的时候 GLM 已经第一轮分析的差不多了，它找到了：**反爬可一行绕过、AES 密钥纯纯硬编码、会实时记录键盘、追踪鼠标移动、操作员实时操控** 等信息

![[2026-07-2nd_bug-x-premium-20260724_00-03-48.webp]]

并且 GLM 还很主动的问我要不要继续做，我说那你就给我丫的往死里干，看看能不能挖出来更多的信息。

第二次获得了：**域名所有者、DNS 解析链、CDN 边缘 IP 归属、IP 和同 IP 的诈骗站**。

然后还写了一份告诉我应该按照什么样的流程一一去哪里举报。

![[2026-07-2nd_bug-x-premium-20260724_00-05-11.webp]]

已经不得不感慨现在模型的强大了。很难想象之后开源大模型逐渐追上现在的闭源 SOTA 大模型会是怎么样的效果。

## 惊天 X 蓝标大炒作

这周还有个很有意思的事情，要从老马在 X 上搞出的一个支付 BUG 说起。

在 X 如果使用德国节点，使用一个已经有了 X Premium 的账号，给其他账号赠送 X 会员，在使用德区 IP 支付的时候可以选择银行转账，但是实际不需要完成转账也可以赠送。

这个 BUG 一开始我是在 L 站看到了，应该是已经发现有一段时间了但是之前一直都是在 TG 传播所以知道的人也不是很多。

刚好我之前已经自己开了一个小号使用 X Premium，本来是想运营一下看看数据的，既然是小号那么玩玩这个也无所谓了。于是就给我自己的大号赠送了一个 **X Premium+**，也就是最贵的那一档会员——**一年**。

另外就是这个东西是可以裂变的，收到赠送的人也可以使用这个办法开始免费赠送会员给其他人，整个就成指数级分布了。

第二天早上起来这个东西已经被老马紧急拉闸了，与此同时 nsy 也醒来了发现自己的账号被上了蓝标。开始纷纷发帖子。

## 去了一趟广州

这周和另一个朋友约了在广州吃个饭，顺便也好久没有去广州溜达了，刚好去广州溜达一下。

过去去广州是坐高铁的，一来是 11 号线可以直达高铁站，而且高铁一眨眼就到了广州。但是鉴于最近确实没多少钱，所以开始研究一下有没有便宜的办法去广州。**最后选择了城际列车**。

**大概单程是 35 左右**，大巴也要 25，而且这个地方我还可以坐地铁直接到，也还算得上是比较物美价廉了。

![[2026-07-2nd_bug-x-premium-20260724_01-04-57.webp]]

车子是和高铁有点类似的动车，不过车内的座位是先到先得的，说是无座但是只要有位置的话就是可以坐的。

![[2026-07-2nd_bug-x-premium-20260724_01-05-07.webp]]

可能缺点就是城际到的是广州偏南的地方，进城大概还需要小一个小时的地铁。但是考虑到我深圳进个城差不多也要一小时，其实感觉还是可以接受的。

---

中午吃了个粤菜，说实话量居然还是意外的大。另外也是把我上周买的大果给带上了。

![[2026-07-2nd_bug-x-premium-20260724_01-06-57.webp|]]

下午的时候去逛了逛广州类似深圳大中华的地方。感觉就是广州周末这种地方的人多的不是一点半点，好悬差点没给我挤死咯，在深圳哪里看得到这么多的人。

![[2026-07-2nd_bug-x-premium-20260724_01-09-14.webp|]]

另外还得提一嘴，广州似乎不太讲究先下后上。每次我想要下车的时候还没来得及下就已经有站台上的人往里挤了，在传说中的体育西路也更是变态。在深圳的换乘大站都不至于这样的。

吃过晚饭之后就再次坐上回去的城际了。因为前一天基本上没怎么睡觉导致我在车上摇摇欲睡几乎好几次都倒在了我旁边的大哥身上，在城际上更是顶不住了直接开睡，一直睡到到了深圳才开始迷迷糊糊的醒来。
