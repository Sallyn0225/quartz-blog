### 疯狂崩溃的opencode

似乎是因为win上的bun有问题，加上opencode的作者自己似乎都是在用AI写代码，3k多个issue完全不见减少，~~说实话oh-my-opencode这个插件修复的都比本体勤快~~。最明显的就是在我使用opencode一旦碰到了需要使用LSP的时候，opencode马上就会崩溃。这个问题似乎只有在WSL中或者mac中可能才会表现得比较好。

![[2026-01-5th_some-issue-when-vibe-coding-20260207_12-19-05.webp]]

> [!tip] 官方的提示
> 虽然 OpenCode 可以直接在 Windows 上运行，但为了获得最佳体验，我们建议使用适用于 Linux 的 Windows 子系统 (WSL)。WSL 提供了一个与 OpenCode 功能无缝集成的 Linux 环境。
